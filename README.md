# Simple Calculator in C

My first C calculator program.

## What it does
Takes two numbers `a` and `b` as input and calculates:
- Sum (a + b)
- Subtraction (a - b)
- Multiplication (a * b)
- Division (a / b)
- Modulus (a % b)

## How to run
```bash
gcc practice1.c -o calculator
./calculator
```
